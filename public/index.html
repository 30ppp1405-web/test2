Features

Everything you need for customer support

A complete live chat solution — from embeddable widget to powerful agent dashboard.

⚡

Real-time Messaging

Instant messaging powered by Socket.io. Messages appear in real-time without any refresh.

⌨️

Typing Indicators

See when visitors are typing before they hit send. Agents see visitor typing too.

📎

File & Image Sharing

Customers and agents can share files, images, and documents up to 5MB directly in chat.

🎛️

Agent Dashboard

Manage all conversations from a beautiful dark dashboard. Filter, search, and resolve chats.

👥

Multi-Agent Support

Multiple agents can be online simultaneously. See who's online in real-time.

🔔

Push Notifications

Browser notifications alert agents when new conversations start, even when tab is in background.

✅

Conversation Resolution

Mark conversations as resolved. Reopen them if the customer has follow-up questions.

⚡

Canned Replies

Type trigger shortcuts like /hello for instant pre-written responses.

🌐

Embeddable Anywhere

Add the widget to any website with a single <script> tag. Zero dependencies.

How it works

Up and running in 3 steps

1

Embed the Widget

Add one script tag to your website's HTML. The widget loads automatically.

2

Agent Signs In

Open the dashboard and sign in. You'll see incoming conversations in real-time.

3

Start Chatting

Visitors click the bubble, fill in their info, and chat begins instantly.
